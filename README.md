# One-Sentence Absurd Invention Pitch

A program that writes a single-sentence pitch for an absurd household invention that fixes a small daily annoyance, with the joke carried by the invention itself.

Bounty: [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)

## Run

```sh
python3 main.py
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
The file holds exactly one sentence of 1–220 characters, with no
trailing newline, and the program reads it back to verify it before
exiting. Python 3 standard library only; no network access.
